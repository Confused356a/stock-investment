## 分档定义

“分档”列只记录档次，不显示颜色。

“可观档”是动态价格档位，要求基本面合格且当前价格进入参考买入区间。价格离开该区间后，分档应随之降为合理档或合理档偏高。“价格信号”列统一显示颜色：🟢 表示收盘价触及/低于参考买入价；🟠 表示收盘价高于当前观察区间上沿或价格明显偏高；`—` 表示暂未触发。绿色信号优先于橙红信号。为减少每日判断漂移，收盘价距离观察区间上沿不超过2%（或已经突破）视为接近/超过上沿，高于参考买入价10%以上视为明显溢价；任一条件满足即标记为价格偏高。

- **梭哈档**：仅用于记录极高确定性、估值有显著安全边际且风险可控的标的；当前没有公司进入此档。现实投资中不建议真正梭哈。
- **可观档**：基本面较好且当前价格进入参考买入区间，适合分批研究或配置。
- **合理档**：公司质量尚可或估值合理，但安全边际一般，需要等待更好价格或更强业绩催化。

## 更新规则

每次新增或更新公司时，记录更新日期、最新收盘价及收盘日、最新财报日期、PB、ROE、股息率、分档变化、上调/下调理由和主要风险。推荐买入列中的“✓”表示当前分析下建议分批买入；空白或“—”表示继续观察。估值指标随股价变化，不能脱离日期和口径比较。
