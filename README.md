## 分档定义

- **梭哈档**：仅用于记录极高确定性、估值有显著安全边际且风险可控的标的；当前没有公司进入此档。现实投资中不建议真正梭哈。
- **可观档**：基本面较好、估值有吸引力，但仍需跟踪业绩验证，适合分批研究或配置。
- **合理档**：公司质量尚可或估值合理，但安全边际一般，需要等待更好价格或更强业绩催化。

## 更新规则

每次新增公司时，记录最新财报日期、股价日期、PB、ROE、股息率、分档变化、上调/下调理由和主要风险。估值指标随股价变化，不能脱离日期和口径比较。
