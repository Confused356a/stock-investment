## 分档定义

“分档”列只记录档次，不显示颜色。

“可观档”是动态价格档位，要求基本面合格且当前价格进入参考买入区间。价格离开该区间后，分档应随之降为合理档或合理档偏高。“价格信号”列统一显示颜色：🟢 表示收盘价触及/低于参考买入价；🟠 表示收盘价高于当前观察区间上沿或价格明显偏高；`—` 表示暂未触发。绿色信号优先于橙红信号。

- **梭哈档**：仅用于记录极高确定性、估值有显著安全边际且风险可控的标的；当前没有公司进入此档。现实投资中不建议真正梭哈。
- **可观档**：基本面较好且当前价格进入参考买入区间，适合分批研究或配置。
- **合理档**：公司质量尚可或估值合理，但安全边际一般，需要等待更好价格或更强业绩催化。

## 更新规则

每次新增或更新公司时，记录更新日期、最新收盘价及收盘日、最新财报日期、PB、ROE、股息率、分档变化、上调/下调理由和主要风险。推荐买入列中的“✓”表示当前分析下建议分批买入；空白或“—”表示继续观察。估值指标随股价变化，不能脱离日期和口径比较。

## 历史回测参考买入区间（非保证）

本仓库不再把参考价格表述为“80%胜率”。截至本次回测，在当前16只A股样本中，按行业估值模型触发信号后，持有约12个月的历史盈利率约为70.1%，持有约24个月的历史盈利率约为75.0%。这只是特定样本、特定规则和特定历史区间下的信号盈利比例，不是未来收益概率，也不是收益保证。

参考价格仍按行业模型计算：银行使用PB—ROE，食品、消费和家电使用归一化EPS与保守PE，通信使用股息率，周期股使用中周期盈利。价格触及区间只代表进入研究和分批布局区间，不代表一次性买入，更不代表梭哈。后续新增股票必须先按同一规则回测，再决定是否标注为可观档。
