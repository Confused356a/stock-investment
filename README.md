## 分档定义

“分档”列只记录档次，不显示颜色。

“价格信号”列统一显示颜色：🟢 表示公司属于可观档，或收盘价触及/低于参考买入价；🟠 表示收盘价高于当前观察区间上沿，或相对参考买入价溢价过高；`—` 表示暂未触发。绿色信号优先于橙红信号。

- **梭哈档**：仅用于记录极高确定性、估值有显著安全边际且风险可控的标的；当前没有公司进入此档。现实投资中不建议真正梭哈。
- **可观档**：基本面较好、估值有吸引力，但仍需跟踪业绩验证，适合分批研究或配置。
- **合理档**：公司质量尚可或估值合理，但安全边际一般，需要等待更好价格或更强业绩催化。

## 更新规则

每次新增或更新公司时，记录更新日期、最新收盘价及收盘日、最新财报日期、PB、ROE、股息率、分档变化、上调/下调理由和主要风险。最后一列“✓”表示当前分析下建议分批买入；空白或“—”表示继续观察。估值指标随股价变化，不能脱离日期和口径比较。

## 推荐价格口径

“80%胜率口径参考买入价”不是收益保证，也不是经过严格历史回测得到的统计概率。它表示：在当前盈利、估值和行业假设不发生明显恶化的前提下，采用保守估值并留出约20%安全边际后的价格，用于提高未来12—24个月获得正收益的可能性。真正的胜率还取决于持有期限、收益目标、分红、市场环境和公司业绩；价格跌到参考价后仍需重新检查基本面。

价格触及参考价只代表进入研究和分批布局区间，不代表一次性买入，更不代表梭哈。
